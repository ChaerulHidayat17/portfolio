PROSES BELAJAR SAYA

Cara Saya Menyelesaikan Masalah IT dengan Bantuan AI Agent

Sebagai fresh graduate, saya sadar keahlian coding saya masih terus diasah. Namun dengan memahami konsep dasar sistem operasi dan berani bereksperimen menggunakan AI Agent sebagai rekan belajar, saya terbantu untuk mengubah ide-ide otomasi menjadi alat kerja nyata yang bermanfaat.

01

Pelajari Alur Kerja IT

Mempelajari apa saja rutinitas teknis yang memakan waktu: install aplikasi berulang kali, pencatatan aset manual, atau pengecekan IP jaringan.

02

Rancang Kebutuhan Skrip

Memetakan perintah apa yang dibutuhkan: perintah Winget untuk aplikasi, WMI query untuk hardware, atau curl untuk transmisi data.

03

Bekerja Bersama AI Agent

Memanfaatkan AI Agent (Hermes Agent / LLM) untuk membantu menyusun skrip PowerShell atau Python secara terstruktur dan modular.

04

Uji Langsung di Perangkat

Mengeksekusi dan mencoba langsung di laptop serta lab komputer pribadi, memperbaiki kesalahan, hingga benar-benar berfungsi dengan baik.
