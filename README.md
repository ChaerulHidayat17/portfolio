# 🌐 Chaerul Hidayat — Enterprise IT Infrastructure & Systems Portfolio

> Technical portfolio of **Chaerul Hidayat** ([@ChaerulHidayat17](https://github.com/ChaerulHidayat17)) showcasing enterprise zero-touch workstation provisioning, automated IT asset management (ITAM), and Linux headless infrastructure operations.

---

## 🚀 Featured Systems & Implementations

* **[DeskCraft](https://github.com/ChaerulHidayat17/deskcraft)**: Precision Zero-Touch Workstation Provisioning Platform (PowerShell in-memory engine, Winget unattended deployment, Cloudflare DNS).
* **[AssetDesk](https://github.com/ChaerulHidayat17/assetdesk)**: Automated IT Asset Management (ITAM), zero-touch BIOS serial extraction, mass division fleet rollout hub, physical barcode label generation.
* **[NodePulse](https://github.com/ChaerulHidayat17/nodepulse)**: Headless Server Telemetry & Battery Power Manager (Linux sysfs, psutil, thermal monitoring).
* **[GadgetFlow](https://github.com/ChaerulHidayat17/gadgetflow)**: Smartphone Reseller Inventory, Daily Sales Bookkeeping & Interactive Telegram Bot.
